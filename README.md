## 📌 研究背景与严苛筛选准则 (3重硬核条件)

在A股三十余载发展历程（全市场 5,300+ 家上市公司）中，绝大部分企业受制于宏观周期、资本开支扩张或盈利波动，曾发生过分红中断。

根据投资者的明确量化要求，本报告设立以下**三重硬核准入条件**：
1. **分红全勤零容忍**：自 IPO 上市首日起，每一个会计年度均实施现金分红，**不能中断**。不论是任何原因（行业下行、再融资、疫情冲击、外部波动等），**只要中断一次即刻不入选**！
2. **市值门槛硬约束**：**总市值必须在 200 亿元及以上**（过滤微盘小市值波动，聚焦具备机构配置流动性的大中盘核心蓝筹）。
3. **板块标的界定**：**不考虑北交所股票（8/92代码），不考虑科创板股票（688代码）**，聚焦于沪深主板与创业板成长龙头。

经过对全市场历史分红数据库的多维穿透与交叉核验，最终精选出 **47 家** 恪守分红契约的长跑核心资产。

## 📈 专题剖析 3：近5年复合年化（DRIP vs 非DRIP）与复利财富测算

- **机制本质**：
  - **Non-DRIP（不复投）**：仅计算股票价格上涨的复合年化，现金分红作为闲置现金流未再买入股票。近5年全样本平均复合年化为 **+5.29%**。
  - **DRIP（分红再投资）**：在历次除权除息日将所得现金红利全额折算为股份复购。近5年全样本平均复合年化跃升至 **+9.61%**。
- **复利剪刀差（+4.32% / 年）的财富量级差距**：
  - 以初始投资 **100,000 元** 为例，持有 5 年：
    - Non-DRIP 终值：约 **129,400 元**（累计收益 +29.4%）
    - DRIP 终值：约 **158,210 元**（累计收益 +58.2%）
    - **DRIP 创造超额财富 28,810 元，累计净利润相比不复投高出 98.0%！**
